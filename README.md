# модуль авторизации и регистрации пользователей

Модуль аутентификации и авторизации для Java приложений с поддержкой JWT токенов и ролевой моделью доступа.

##  Функциональности

###  Аутентификация
- **Регистрация пользователей** с валидацией данных
- **Логин/логаут** с JWT токенами
- **Подтверждение email** (опционально)
- **Восстановление пароля**

###  Авторизация
- **Ролевая модель доступа** (ROLE_ADMIN, ROLE_USER)
- **JWT валидация** для каждого запроса
- **Интеграция с Spring Security**

###  Управление пользователями
- **CRUD операции** для пользователей
- **Смена пароля**
- **Обновление профиля**

##  Технологии

### Backend
- **Java** - основной язык программирования
- **Spring Boot** - фреймворк
- **Spring Security** - аутентификация и авторизация
- **Spring Data JPA** - работа с базой данных
- **JJWT** - работа с JWT токенами
- **PostgreSQL** - база данных
- **Maven** - управление зависимостями
